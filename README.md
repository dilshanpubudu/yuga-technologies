# YUGA Technologies Website

Responsive static website recreation based on the saved YUGA Technologies site content.

## Included
- Responsive landing page with Expertise, Possibilities, Our approach, About, FAQ and Contact sections
- Mobile navigation
- Floating WhatsApp contact button
- Contact form that prepares the enquiry in WhatsApp
- WhatsApp number configured as +94 78 965 1154

## Run locally
Open `index.html` in a browser. For local development, you can also run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Deploy
Upload the contents of this folder to any static hosting provider (Cloudflare Pages, Netlify, GitHub Pages, etc.).

Note: This is a recreated standalone source project based on the saved website content, not a recovered copy of the original platform's internal source code.
